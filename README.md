# alexandercaldwell.com

Source for [alexandercaldwell.com](https://alexandercaldwell.com), the personal finance blog of
Alexander Caldwell: guides on pay stubs, payroll, tax, finance, paychecks, W-2 and 1099 forms.

The site is static HTML generated by a small, dependency-free Python script. Everything the
browser needs is committed, so any static host (GitHub Pages, Vercel, Netlify, S3) can serve the
repository root as-is.

## Layout

```
build.py              # generator: run `python3 build.py` from the repo root
content/posts/*.html  # one article per file (metadata header + HTML body)
assets/style.css      # styles; brand palette #3f2df0 / #1bdec8 / #3c4b5c
assets/favicon-32.png             # favicons cropped from the author photo
assets/favicon-192.png  assets/apple-touch-icon.png
assets/alexander-caldwell.jpg     # author photo (400x400) + -sm.jpg (192x192)
assets/og-image.jpg               # social sharing card (1200x630)
assets/blog/<slug>.jpg            # article cover (1200w) + <slug>-sm.jpg (620w)

index.html            # generated: home page
about/  blog/         # generated: bio page, all-articles page
terms/  privacy/      # generated: legal pages
paystubs/ payroll/ tax/ finance/ paycheck/ w-2-form/ 1099-forms/
                      # generated: one folder per category, with a sub-folder per article
404.html sitemap.xml robots.txt   # generated
vercel.json           # optional host config (clean URLs, headers)
```

## Writing an article

Create `content/posts/<slug>.html`:

```
title: How to Read Your Pay Stub
slug: how-to-read-your-pay-stub
category: paystubs
date: 2026-08-31
description: One or two sentences used for the card, meta description and JSON-LD.
---
<p>Article body in HTML.</p>
```

`category` must be one of `paystubs`, `payroll`, `tax`, `finance`, `paycheck`, `w-2-form`,
`1099-forms`. Repeat the `summary:` line for each key-takeaway bullet.

To give the article a cover image, drop `assets/blog/<slug>.jpg` (1200x675) and
`assets/blog/<slug>-sm.jpg` (620x349) next to the others; the build picks them up by
filename and uses them for the card thumbnail, the article hero, the Open Graph image and
the JSON-LD `image`. Alt text is generated from the title. Then run the build and commit
the result:

```bash
python3 build.py
git add -A && git commit -m "Add article: ..."
```

The build regenerates every page, category listing, the sitemap and robots.txt, and removes
generated folders for posts that no longer exist.

## Site settings

Author bio, categories, menu order, social links and the site URL live at the top of
`build.py`. Colours and spacing live in `assets/style.css`.

## Local preview

```bash
python3 build.py
python3 -m http.server 8000   # then open http://localhost:8000/
```
